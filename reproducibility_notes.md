# Reproducibility notes

The manuscript specifies the coefficient-perturbation procedure in Section 2.11 and specifies 10,000 coefficient configurations. It does not specify a separate random seed for that analysis. The public implementation therefore uses a fixed seed of 20260811 for reproducibility.

For the within-domain analysis, the component-level configurations are taken from the illustrative examples in Sections 2.3–2.8. These are:

- C = [1, 1, 1, 0]
- I = [1, 1, 1, 0]
- R = [1, 1, 1, 1]
- H = [1, 1, 1, 0]
- D = [1, 0.5, 0, 0.5]
- U = [0.5, 1, 0.5, 1]

With the Table 2 within-domain coefficients, these produce C = 0.80, I = 0.80, R = 1.00, H = 0.85, D = 0.575 and U = 0.75 before perturbation.

The rounded Table 4 summary values generated by the script are:

- within-domain: mean 0.745, median 0.745, 2.5th percentile 0.738, 97.5th percentile 0.751, minimum 0.730, maximum 0.755;
- joint: mean 0.744, median 0.745, 2.5th percentile 0.716, 97.5th percentile 0.768, minimum 0.688, maximum 0.780.

The manuscript's reported observed extrema can differ slightly because the manuscript does not specify the coefficient-analysis seed. The code does not alter or hard-code the manuscript's reported results.
