# AHT Decision-Support Framework — reproducible implementation v2.0

This repository contains the Python implementation accompanying the manuscript:

**A Knowledge-Based Decision-Support Framework for Structured Assessment of Suspected Abusive Head Trauma**

## Scope

The implementation reproduces the mathematical framework, representative scenario analyses, domain-contribution analysis, the retinal/imaging contour analysis, the illustrative clinical-case Monte Carlo simulation, and the coefficient-perturbation sensitivity analysis described in the manuscript.

The framework output is a **diagnostic support score**. It is not a statistically estimated or clinically validated probability of AHT.

## Figure numbering

Figure 1 in the manuscript is the conceptual flowchart and is not generated by Python.
The Python script generates:

- Figure 2 — effect of the baseline parameter β₀
- Figure 3 — minimum, reference, and maximum scenarios
- Figure 4 — relative contribution of active diagnostic domains
- Figure 5 — joint influence of retinal (R) and imaging (I) components
- Figure 6 — illustrative clinical-case Monte Carlo simulation

## Model specification

- β₀ = 0.50
- C = 0.15
- I = 0.25
- R = 0.30
- H = 0.10
- D = 0.10
- U = 0.10

The six domain-level coefficients sum to 1. Within-domain coefficients are those reported in Table 2 of the manuscript:

- Clinical: 0.40, 0.20, 0.20, 0.20
- Imaging: 0.30, 0.30, 0.20, 0.20
- Retinal: 0.25, 0.25, 0.30, 0.20
- History: 0.40, 0.25, 0.20, 0.15
- Differential diagnosis: 0.35, 0.30, 0.20, 0.15
- Diagnostic uncertainty: 0.30, 0.30, 0.20, 0.20

## Clinical-case simulation

The illustrative clinical-case analysis uses:

- C fixed at 0.8
- I sampled from U(0.8, 1.0)
- R sampled from U(0.7, 0.9)
- H sampled from U(0.4, 0.6)
- D sampled from U(0.3, 0.5)
- U sampled from U(0.4, 0.6)
- n = 10,000
- seed = 20260811

The implementation reproduces the manuscript's reported mean, SD and percentile values to the displayed precision.

## Coefficient sensitivity analysis

Section 2.11 describes independent ±50% perturbation of the six domain-level coefficients and the four within-domain coefficients within each domain, followed by renormalization to preserve the sums of 1.

For the within-domain analysis, the implementation uses the illustrative component-level configurations described in Sections 2.3–2.8:

- C: [1, 1, 1, 0]
- I: [1, 1, 1, 0]
- R: [1, 1, 1, 1]
- H: [1, 1, 1, 0]
- D: [1, 0.5, 0, 0.5]
- U: [0.5, 1, 0.5, 1]

These produce the illustrative domain scores C = 0.80, I = 0.80, R = 1.00, H = 0.85, D = 0.575 and U = 0.75 before coefficient perturbation.

The manuscript specifies 10,000 coefficient configurations but does not specify a separate random seed for this sensitivity analysis. This implementation uses seed **20260811** so that the published code is fully reproducible. The resulting Table 4 values reproduce the manuscript values to three decimal places. The exact observed minimum and maximum in Table 3 can depend on the coefficient-perturbation seed and are therefore not treated as fixed validation targets.

## Running the code

Install the dependencies:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python Framework2.py
```

The script creates or updates the `figures/` and `data/` directories automatically.

## Output files

`figures/` contains Figures 2–6.

`data/` contains the numerical data underlying the figures, the clinical-case summary, the additional scenarios, and the coefficient-sensitivity tables.

## Reproducibility

The script performs internal checks of the principal manuscript results before generating the outputs. It reports `Verification: PASS` when the baseline scenarios and clinical-case simulation agree with the manuscript specification.
